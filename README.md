# Chatbot Application for New Student Admission Services

This repository contains the undergraduate thesis of Lathifa Magfirah Bachmid from the Informatics Engineering program at Sam Ratulangi University.

The research focuses on developing a chatbot application to assist prospective students in accessing information about the new student admission process.

Technologies used:
- Python
- Natural Language Processing (NLP)
- Wit.ai
- Telegram Bot API
